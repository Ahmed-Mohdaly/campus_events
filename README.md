## 📌 Project Overview
**Campus Events Guide** is a responsive, multi-page static website built strictly using semantic **HTML5** and **CSS3** (without JavaScript, external frameworks, or inline styles). The website enables university students to explore campus events, view detailed event agendas and media, check the overall timetable, and register for upcoming activities.

All five pages are connected through a unified user journey centered around the main featured event:
* **Featured Event:** Zewail AI & Tech Summit
* **Date:** 2026-11-15
* **Venue:** Helmy Institute Hall
